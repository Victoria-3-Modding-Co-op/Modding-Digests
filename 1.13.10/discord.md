# Release 1.13.10
## Major Modding Feature
This update introduces so-called script containers to the scripting language.

These can function like structs in other languages and hold variables while themselves being full-fledged objects/scopes.

A full introduction can be found in [script_containers.md](https://github.com/Victoria-3-Modding-Co-op/Modding-Digests/blob/main/1.13.10/script_containers.md).
